# Гульки (gulki) 0.2.0

Первая версия независимого JavaScript-плагина для Lampa Android TV. С подключаемым поиском The Pirate Bay без ключа и собственными источниками. Учётные данные не встроены. Интерфейс на русском, управляется пультом через стандартные окна Lampa.

## Быстрый запуск без API-ключа

После обновления плагина полностью перезапустите Lampa. Откройте **Гульки → The Pirate Bay — поиск без ключа** и введите название фильма. Источник добавится в собственные настройки «Гульки» автоматически; повторный выбор не создаёт дубликатов. Через **Источники → Управление источниками** его можно выключить или удалить. Отдельная кнопка добавления также есть в «Источники».

Поиск использует публичный endpoint `https://apibay.org`, который указан в JavaScript самого The Pirate Bay. Ключ, регистрация и Jackett для этого источника не нужны. Искать по английскому названию обычно полезнее. Запрашиваются категории фильмов 201, 202, 207, 209, 210, 211; ответы дополнительно фильтруются по этим категориям. Пустой запрос загружает публичный top100 Video, после чего остаются только указанные категории фильмов.

На Android запрос идёт через `Lampa.Reguest.native`, когда этот интерфейс доступен. Обычный браузерный запрос может блокироваться CORS: при сетевой проверке endpoint не вернул `Access-Control-Allow-Origin`. Веб-версия Lampa поэтому не считается подтверждённым вариантом. На реальном Android TV нативный запрос и воспроизведение ещё не проверены; блокировки или недоступность самого источника тоже возможны. Плагин сообщает об ошибке и не включает сторонний прокси.

## Что реализовано

- Отдельный пункт меню «Гульки» и каталог списком, по 50 фильмов на странице.
- Поиск одновременно по нескольким подключённым источникам; отказ одного не скрывает результаты остальных. Тайм-аут 20 секунд, отмена и защита от запоздавшего ответа.
- The Pirate Bay без ключа, Jackett JSON API и подключаемые JSON API по описанному ниже контракту.
- Фильтры по году и студии среди уже полученных результатов.
- Объединение по явному `movieId`, иначе по названию, году и студии. При объединении по названию разные годы не объединяются. Без года и ID автоматического объединения нет. Эвристика может ошибаться: для точного каталога нужны метаданные.
- Удаление повторов одной magnet-раздачи внутри фильма, выбор качества, затем конкретной раздачи с числом сидов и размером.
- Передача выбранной раздачи в `Lampa.Torrent.start`: штатная Lampa выполняет подключение к TorrServer, выбор файла и воспроизведение.

## Установка через GitHub Pages

1. Загрузите содержимое этой папки в репозиторий GitHub. Файл `plugin.js` должен оказаться в корне публикуемой папки.
2. Загрузите также скрытую папку `.github` из архива. В Settings → Pages выберите Source → GitHub Actions. Файлы должны находиться в корне ветки `main`.
3. Откройте Actions → Verify and publish Gulki и дождитесь успешной проверки и публикации. При первом добавлении workflow в `main` запуск произойдёт автоматически; повторный запуск доступен через Run workflow. После успешной публикации проверьте адрес `https://ВАШ-ЛОГИН.github.io/ВАШ-РЕПОЗИТОРИЙ/plugin.js`: должен открываться JavaScript, а не HTML/404.
4. Добавьте этот адрес в плагины Lampa, перезапустите приложение. Откройте «Гульки» → «Источники».

Готовая ссылка для установки в Lampa: https://dmytrurphy.github.io/Gulki/plugin.js

Первая публикация через GitHub Actions завершилась успешно: https://github.com/Dmytrurphy/Gulki/actions/runs/41906552337 . Содержимое файла на Pages сверено с проверенной сборкой побайтно. Проверка на реальном Android TV и TorrServer остаётся отдельным шагом.

## Источники

«Добавить Jackett»: введите имя, базовый URL сервера, ID индексатора (либо `all`) и API-ключ. Плагин запрашивает `/api/v2.0/indexers/ID/results?apikey=…&Query=…`. Для нескольких индексаторов можно добавить несколько записей с разными ID. Ключ сохраняется только в локальном хранилище Lampa; в запросах к вашему Jackett он передаётся в URL по протоколу Jackett. Поле ввода ключа не маскируется — учитывайте это при демонстрации экрана.

«Добавить JSON-источник»: URL вида `https://YOUR-SERVER/search?q={query}`. `{query}` заменяется безопасно закодированным запросом. Сервер должен вернуть:

```json
{
  "items": [{
    "title": "Example Film (2024) 1080p",
    "movieTitle": "Example Film",
    "movieId": "your-global-catalog-id",
    "year": 2024,
    "studio": "Example Studio",
    "quality": "1080p",
    "magnet": "magnet:?xt=urn:btih:0123456789012345678901234567890123456789",
    "seeders": 5,
    "size": 1073741824
  }]
}
```

Это пример схемы, не реальная раздача. `title` и пригодная `magnet` либо `link` обязательны. Остальные поля необязательны. `movieId` должен обозначать один и тот же фильм во всех подключённых источниках. Студия не угадывается из названия: без метаданных отображается «Не указана». Jackett обычно не отдаёт студию, поэтому полезный фильтр по студиям требует JSON-источника с этим полем. Год и качество при отсутствии явных значений извлекаются из названия эвристически.

Для начального каталога выберите «Обновить каталог из источников»: отправляется пустой запрос. Поддержка такого запроса зависит от источника. Если он не поддержан, используйте поиск. Каталог хранится в памяти до перезапуска; это не собственная полная база фильмов. На один источник обрабатывается максимум 3000 результатов; серверная пагинация в v0.1 отсутствует.

Прямой адаптер JacRed не заявлен: разные серверы используют разные схемы. Для такого сервера нужен совместимый JSON endpoint либо отдельный адаптер. Существующие Jackett/JacRed в Lampa не читаются и не изменяются. Все записи настроек этого плагина идут только в `gulki_sources`.

## TorrServer и сеть

Настройте TorrServer штатными средствами Lampa. Для пути через TorrServer на Android в настройках Lampa должен быть выбран соответствующий встроенный режим torrent-клиента: исходный код Lampa может иначе передать торрент внешнему Android-приложению. Плагин сам эти настройки не меняет. Проверьте выбранный режим на устройстве.

GitHub Pages хранит только плагин. Индексаторы и TorrServer должны быть доступны телевизору; `localhost` на телевизоре означает сам телевизор. HTTPS-страница может блокировать HTTP-запросы (mixed content), а серверы могут запрещать CORS. Плагин не обходит эти ограничения и не включает публичный прокси. При необходимости используйте собственный доступный HTTPS endpoint с корректным CORS. Локальные ключи доступны другим плагинам с доступом к тому же хранилищу; не публикуйте их и не добавляйте в исходники.

## Сборка и проверки

Зависимостей для сборки нет:

```sh
python3 build.py
node tests/run.cjs
```

`plugin.js` — последовательное объединение `src/core.js` и `src/lampa.js`, без сборщика и загрузки внешних библиотек. Для Android-поиска The Pirate Bay также используются `Reguest.native` и `Platform.is`. Требуется Lampa с `Select`, `Input.edit`, `Storage`, `Controller`, `Listener`, `Torrent.start` и jQuery.

См. [docs/VALIDATION.md](docs/VALIDATION.md) для фактических результатов и проверки на ТВ. Это первая версия; совместимость с конкретной сборкой Lampa, реальным индексатором и TorrServer пока не подтверждена.

## Автоматическая публикация

Workflow `.github/workflows/pages.yml` собирает плагин, проверяет соответствие исходников готовому файлу и запускает тесты. Только после успешных проверок ветка `main` публикуется в Pages. Для pull request выполняются проверки без публикации. В публичный результат попадают только `plugin.js`, `LICENSE` и `.nojekyll`. Рабочие настройки и API-ключи в репозиторий добавлять не нужно.

Если основная ветка называется иначе, замените `main` в workflow на её имя. Автоматическая публикация подготовлена по документации GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages . Удалённый запуск workflow проверен: сборка, тесты и публикация завершились успешно.
